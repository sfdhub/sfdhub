
Что такое постоянный ток?

Постоянный ток (DC) — это электрический ток, который течет в одном направлении и имеет постоянное значение.



Какова цель туманных вычислений?

Туманные вычисления (fog computing) предназначены для обработки данных ближе к источнику их происхождения, что уменьшает задержки и нагрузку на центральные облачные системы.



Сопоставьте уровни модели TCP/IP с их функциями.

Уровень прикладных программ (Application) — обеспечивает интерфейсы для приложений.
Транспортный уровень (Transport) — обеспечивает надежную передачу данных.
Сетевой уровень (Internet) — отвечает за маршрутизацию данных.
Канальный уровень (Link) — управляет передачей данных на физическом уровне.



Каковы два преимущества использования оптоволоконных кабелей по сравнению с медными кабелями?

Высокая пропускная способность и меньшая чувствительность к электромагнитным помехам.



Какой тип цепи обеспечивает несколько путей для протекания тока, чтобы выход из строя одного компонента не повлиял на работу всей цепи?

Параллельная цепь.



Какова роль маршрутизации в сетях передачи данных?

Маршрутизация определяет оптимальные пути для передачи данных между сетями.



Какой инструмент способен измерять сигналы, передаваемые от датчиков к микроконтроллерам, в зависимости от времени?

Осциллограф.



Какая особенность микроконтроллеров делает их пригодными для использования в Интернете вещей?

Низкое энергопотребление и возможность интеграции с различными сенсорами.



Какой язык является примером компилируемого языка программирования?

C++.



Каковы три компонента системы управления?

Сенсор, контроллер и исполнительный механизм.



Какую беспроводную технологию можно использовать для обеспечения пропускной способности до 100 Мбит/с в мегаполисе?

LTE (Long-Term Evolution).



Какой тип компонента не влияет на усиление или управление напряжением или током?

Пассивный компонент, например, резистор.



Какие функции выполняют датчики в цифровом мире?

Датчики собирают данные из окружающей среды и преобразуют их в цифровые сигналы.



Какой программный пакет обычно используется для создания программ для Arduino?

Arduino IDE.



Какой инструмент измеряет отношение напряжения к току на объекте?

Мультиметр (в режиме измерения сопротивления).



Назовите два фактора, влияющих на сетевую безопасность в IoT.

Аутентификация и шифрование данных.



В чем преимущество исполняемой программы, написанной на интерпретируемом языке, по сравнению с компилируемым языком?

Лучшая переносимость и возможность быстрого тестирования и отладки.



Приведите пример системы управления с обратной связью.

Термостатическая система отопления.



Какую команду оболочки Linux можно использовать для поиска определенной строки символов в файле?

grep.



Что такое Raspberry Pi?

Raspberry Pi — это небольшой одноплатный компьютер, используемый для обучения и разработки.



Какие три элемента могут служить входами для микроконтроллера, такого как Arduino?

Датчики температуры, кнопки, фоторезисторы.



Какой дистрибутив Linux используется для разработки операционной системы Raspbian для Raspberry Pi?

Debian.



Что встроено в цифровой объект, например, фотографию или электронное письмо?

Метаданные.



Какой тип электрической цепи перестает работать при повреждении или удалении одного электронного компонента?

Последовательная цепь.



Что используется для ограничения количества тока, протекающего по цепи?

Резистор.



Сопоставьте административную команду Linux с функцией, которую она выполняет. cd, cp, mv, rm.

cd — изменить директорию.
cp — копировать файлы.
mv — переместить или переименовать файлы.
rm — удалить файлы.



Какая беспроводная технология имеет требования к низкому энергопотреблению и скорости передачи данных, что делает ее популярной в приложениях домашней автоматизации?

Zigbee.



Какие меры необходимо предпринять для обеспечения безопасности IoT-устройств?

Использование шифрования, регулярное обновление прошивки, настройка аутентификации.



Какой тип устройства способен создавать физическое движение?

Серводвигатель.



Какой уровень эталонной модели Интернета вещей описывает хранение данных?

Уровень данных (Data layer).
