·Что такое процессы и нити?

Процесс - это программа, которая выполняется в операционной системе. Нить - это часть процесса, которая может выполняться параллельно с другими частями процесса. Нить может быть создана внутри процесса и выполняться параллельно с другими нитями внутри процесса.  
· Как задаются действия, которые должна выполнять создаваемая нить?  
Действия, которые должна выполнять создаваемая нить, задаются при ее создании. Например, можно передать указатель на функцию, которую должна выполнить нить.  
· Можно ли передать нити в качестве параметров не одно число, а
несколько?  
В Нить можно передать в качестве параметров несколько значений, используя структуру данных, такую как массив или свою структуру.  
· Как можно завершить выполнение нити?  
Выполнение нити можно завершить с помощью функции ExitThread.  
· Как задается имя выполняемого файла при запуске нового процесса?  
Имя выполняемого файла задается при запуске нового процесса.  
· Как получить хэндл запущенного процесса?
Хэндл запущенного процесса можно получить с помощью функции OpenProcess.

· В каких случаях завершается работа процесса?  
Работа процесса завершается в следующих случаях:

- Процесс завершает свою работу.
- Процесс был завершен извне, например, пользователем или другим процессом.
- Произошла ошибка в процессе, которая привела к его аварийному завершению.

· Какие функции Windows называются функциями ожидания?  
Функции Windows, которые называются функциями ожидания, позволяют потоку приостановить свое выполнение до наступления определенного события.

· В каких случаях завершается выполнение вызванной функции
ожидания?  
Выполнение вызванной функции ожидания завершается, когда наступает событие, которое она ожидает, или когда происходит ошибка.

· Как узнать причину завершения ожидания?  
Причину завершения ожидания можно узнать с помощью функции GetLastError.

· Как можно гарантировать, что при вызове функции ожидания нить не
будет заблокирована?  
Чтобы гарантировать, что при вызове функции ожидания нить не будет заблокирована, можно использовать функции с таймаутом.

· Что такое «брошенный мьютекс»?  
“Брошенный мьютекс” - это мьютекс, который был захвачен потоком, но не был освобожден.

· Чем пассивное ожидание отличается от активного и какой из этих
типов ожидания реализуют функции ожидания?  
Пассивное ожидание - это ожидание, которое не потребляет процессорное время. Активное ожидание - это ожидание, которое потребляет процессорное время. Функции ожидания реализуют пассивное ожидание.

· Какие имеются типы объектов синхронизации?
мьютексы, семафоры и события.

· Для чего используются имена объектов?
Имена объектов используются для идентификации объектов синхронизации.

· Чем различаются события с ручным сбросом и с автосбросом?
событие с ручным сбросом не переводится в несигнальное состояние после того, как оно было поднято, в то время как событие с автосбросом переводится в несигнальное состояние автоматически.

· Когда событие переводится в несигнальное состояние?  
Когда событие переводится в несигнальное состояние зависит от типа события. Событие с ручным сбросом не переводится в несигнальное состояние после того, как оно было поднято, в то время как событие с автосбросом переводится в несигнальное состояние автоматически

· Когда система удаляет объект?  
Система удаляет объект, когда на него больше нет ссылок.

· Какие различия имеются между событиями и мьютексами?  
Мьютексы и события отличаются тем, что мьютексы используются для синхронизации доступа к ресурсам, а события используются для уведомления потоков о наступлении определенных событий.

· Для решения каких задач используются мьютексы?  
Мьютексы используются для решения задач, связанных с синхронизацией доступа к ресурсам.

· Какие состояния семафора являются сигнальными?  
Семафоры могут иметь несколько состояний, но только два из них являются сигнальными: 0 и больше 0  
· В чем различия между мьютексами и семафорами?  
Мьютексы и семафоры - это механизмы синхронизации, которые используются для защиты критических секций. Мьютексы - это объекты, которые поток может захватить, предотвращая другим потокам захватить его. Семафоры - это переменные, которые используются для управления доступом к ресурсам, которые могут быть разделены между несколькими потоками или процессами  
· Какие состояния процессов и нитей являются сигнальными?  
Сигнальными состояниями процессов и нитей являются состояния, в которых они могут выполняться. В Windows существует пять состояний потоков: готовый, запущенный, ожидающий, задержанный и заблокированный

· В чем различие между мьютексами и критическими секциями?  
Мьютексы и критические секции - это механизмы синхронизации, которые используются для защиты критических секций. Критическая секция - это участок кода, который гарантированно не будет прерван операционной системой. Мьютексы - это объекты, которые поток может захватить, предотвращая другим потокам захватить его
