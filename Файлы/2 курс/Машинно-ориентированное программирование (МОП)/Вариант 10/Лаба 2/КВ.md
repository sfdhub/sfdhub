 1. Для чего нужен оператор ptr?
 2. В чем отличие команд mov AX, offset MASS и lea AX, MASS?
 3. В чем отличие команд mov AX, BX и mov AX, [BX]?
 4. В чем отличие команд mov AX, [BP] и mov AX, [BX] ?
 5. В чем отличие команд mov AX, [BX+2] и mov AX, [BX]\+2 ?
 6. В чем отличие команд mov AX, [BX\]\[SI] и mov AX, [SI\]\[BX] ?
 7. Для организации каких вычислений служат команды loop, loope, loopne?
 8. Модифицирует ли какие-нибудь регистры команда loop ?
 9. Можно ли организовать цикл по счетчику, не используя loop-команды?
10. Можно ли организовать цикл while с помощью одной из loop-команд?
11. Что такое прямой и косвенный переходы?
12. Какие команды выполняют переход по флагу нуля?
13. Какие команды выполняют переход по флагу знака?
14. Какие команды выполняют переход по флагу переноса?
15. Какие команды выполняют переход по флагу переполнения?
16. Какие команды выполняют переход при сравнении беззнаковых чисел?
17. Какие команды выполняют переход при сравнении знаковых чисел?
18. Что делает команда jle [BX]?

Ответы

 1. Оператор `ptr` используется для указания типа данных, на которые указывает указатель.
 2. Команда `mov AX, offset MASS` загружает в регистр AX адрес переменной MASS, а команда `lea AX, MASS` загружает в регистр AX саму переменную MASS.
 3. Команда `mov AX, BX` копирует значение регистра BX в регистр AX, а команда `mov AX, [BX]` копирует значение, на которое указывает регистр BX, в регистр AX.
 4. Команда `mov AX, [BP]` копирует значение из стека по адресу, хранящемуся в регистре BP, в регистр AX, а команда `mov AX, [BX]` копирует значение из памяти по адресу, хранящемуся в регистре BX, в регистр AX.
 5. Команда `mov AX, [BX+2]` копирует значение из памяти по адресу, хранящемуся в регистре BX с добавлением 2 байтов к адресу, в регистр AX. Команда `mov AX, [BX]+2` копирует значение из памяти по адресу, хранящемуся в регистре BX, и добавляет 2 к этому значению.
 6. Команды `mov AX, [BX][SI]` и `mov AX, [SI][BX]` копируют значение из памяти по адресу, вычисленному как сумма значений регистров BX и SI или SI и BX соответственно.
 7. Команды loop используются для организации циклов. loop выполняет переход на метку или адрес при условии, что значение счетчика цикла не равно нулю. loope выполняет переход при условии равенства флага ZF единице (то есть при равенстве). loopne выполняет переход при условии неравенства флага ZF единице (то есть при неравенстве).
 8. Команда loop уменьшает значение счетчика цикла на единицу и модифицирует флаг ZF.
 9. Да, можно организовать цикл по счетчику без использования loop-команд.
10. Да, можно организовать цикл while с помощью одной из loop-команд.
11. Прямой переход - это переход на метку или адрес без условия. Косвенный переход - это переход на метку или адрес по значению указателя или индексного регистра.
12. Команды je (jump if equal), jz (jump if zero), jcxz (jump if CX register is zero) выполняют переход по флагу ZF.
13. Команды js (jump if sign), jns (jump if not sign) выполняют переход по флагу SF.
14. Команды jc (jump if carry), jnc (jump if not carry) выполняют переход по флагу CF.
15. Команды jo (jump if overflow), jno (jump if not overflow) выполняют переход по флагу OF.
16. Команды jb (jump if below), jnae (jump if not above or equal), jnc (jump if not carry) выполняют переход при условии низкого порядка бита CF.
17. Команды jl (jump if less), jnge (jump if not greater or equal) выполняют переход при условии низкого порядка бита SF и OF
18. Команда `jle` - это инструкция перехода в ассемблере, которая переходит на метку, если значение флагов `ZF` или `SF` установлено. В данном случае, `jle [BX]` перейдет на метку, если значение в регистре `BX` меньше или равно нулю.
