1. Что такое событие в программе с графическим интер- фейсом?
2. Чем обрабатывается событие?
3. Как правильно удалять обработчики события?
4. В каком окне(вкладке) проекта можно посмотреть пере- чень возможных событий для конкретного элемента управления?

1. **Событие**[ в программе с графическим интерфейсом - это изменение состояния объекта, например, нажатие кнопки, перемещение мыши, изменение текста в поле ввода и т.д](https://en.wikipedia.org/wiki/Event-driven_programming).
2. **Событие** обрабатывается с помощью **обработчика событий**, который является функцией, вызываемой при возникновении события. [Обработчик событий связывается с объектом, генерирующим событие, и вызывается автоматически при возникновении события ](https://en.wikipedia.org/wiki/Event-driven_programming).
3. Для удаления можно использовать оператор -= либо функцию
4. В Visual Studio можно посмотреть список возможных событий для конкретного элемента управления в окне **Свойства**. Для этого необходимо выбрать элемент управления на форме и перейти на вкладку **Свойства**. В списке свойств необходимо найти свойство **События** и развернуть его. [В списке отображаются все доступные события для выбранного элемента управления](https://en.wikipedia.org/wiki/Event-driven_programming).
