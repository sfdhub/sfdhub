1. **Конструктор** - это специальный метод класса, который выполняется при создании объекта этого класса. Он может принимать аргументы или не принимать их. Конструкторы используются для инициализации объектов класса и выделения памяти для объектов. [В одном классе может быть несколько конструкторов, которые могут отличаться друг от друга аргументами, типами аргументов или их количеством1](https://www.geeksforgeeks.org/difference-between-constructor-and-destructor-in-c/).
2. **Деструктор** - это специальный метод класса, который выполняется при удалении объекта этого класса. Деструкторы не принимают аргументы и не возвращают значения. [Они используются для освобождения памяти, занятой объектом, и выполнения других завершающих операций1](https://www.geeksforgeeks.org/difference-between-constructor-and-destructor-in-c/).

- Конструктор копирования `Alpha(const Alpha& other)`.
- [Деструктор ](https://www.geeksforgeeks.org/difference-between-constructor-and-destructor-in-c/)`~Alpha()`[1](https://www.geeksforgeeks.org/difference-between-constructor-and-destructor-in-c/).

1. Обращение к члену `abc` с использованием точки будет выглядеть так: `alpha.abc`. Обращение с использованием стрелки будет выглядеть так: `alpha->abc`.
2. Компилятор отличает вызов стандартной операции от вызова перегруженной по типу аргументов, переданных в операцию. В языке С операции `<<` и `>>` могут быть перегружены для разных типов данных. Результат второго выражения `cout<<(a<<3)` будет равен 32.
3. **Отношение включения** в объектно-ориентированном программировании означает, что один класс является подклассом другого класса или реализует интерфейс другого класса. Оно изображается на диаграммах наследования с помощью стрелки соответствующего типа наследования. **Делегирование** - это механизм передачи обязанностей одному объекту от другого объекта.
